## ⚡ Overview

This repository (`cvanuj`) contains the production source code for the personal portfolio of **Anuj Thapa** (BSc Hons Computing student at Informatics College Pokhara, aspiring software engineer).

The entire website is designed with a **dark precision aesthetic**, utilizing semantic HTML5, modern CSS3 (custom properties, flexbox, CSS grid, glassmorphism, responsive breakpoints), and clean vanilla JavaScript without bulky frameworks or external runtime dependencies.

Every project displayed on this portfolio is sourced from and linked to verified GitHub repositories:

   - *3D / WebGL Multiplayer Campus Experience*
   - Three.js, React 19, Node.js, Express 5, Socket.io, JWT Authentication, Web Audio API, PostgreSQL.

7. **[CVanuj (This Portfolio)](https://github.com/anujthapa1/cvanuj)**
   - *Production Web Portfolio*
